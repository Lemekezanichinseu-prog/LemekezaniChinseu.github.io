# Lemekezani Chinseu Portfolio

## Run in VS Code
1. Open this folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click `index.html` → "Open with Live Server".
4. Replace the placeholder email and LinkedIn URL in `index.html`.
5. Put your CV at `assets/cv.pdf` if you want to enable a CV download button.

## Files
- index.html — page structure/content
- style.css — responsive design, animations and dark mode
- script.js — typing animation, mobile menu, dark mode, reveal animations and scroll progress
- images/profile.jpg — uploaded profile photo
